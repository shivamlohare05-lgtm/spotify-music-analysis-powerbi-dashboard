# 🎵 Spotify Music Analytics Dashboard

> An interactive Spotify-themed Power BI dashboard that transforms raw music data into meaningful insights.

## 🚀 About The Project

This dashboard analyzes Spotify's Top Songs dataset and provides insights into:

🎤 Artist Performance  
🎶 Song Popularity Trends  
💿 Album vs Single Distribution  
📈 Monthly Popularity Analysis  
🔞 Explicit vs Non-Explicit Content Analysis  

---

## 📊 Key Metrics

✨ 789 Unique Songs

✨ 27.8K+ Records Analyzed

✨ 89.62 Average Popularity Score

✨ 3.28 Minutes Average Song Duration
